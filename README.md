# Personal Page

클라우드컴퓨팅실습 개인 과제를 위해 제작한 개인 소개 웹페이지입니다.

## 주요 기능

- 개인 프로필 및 자기소개
- 관심 분야 및 수업 목표 소개
- 다크모드 기능
- Memo Frontend 페이지 이동 기능

## 사용 기술

- HTML
- CSS
- JavaScript
